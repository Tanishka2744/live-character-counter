# ✨ Live Character Counter

A modern and responsive **Live Character Counter** built using **HTML, CSS, and JavaScript**.

Users can type in a textarea and see the character count, remaining characters, and progress bar update instantly.

## 🚀 Features

- 🔢 Live character counting
- 🎯 200-character maximum limit
- 📊 Dynamic progress bar
- ⚠️ Warning when approaching the limit
- 🚫 Stops typing after 200 characters
- ✨ Smooth counter animation
- 💎 Modern glassmorphism UI
- 📱 Fully responsive design
- ❌ No external JavaScript libraries

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🧠 JavaScript Concepts

This project helps practice:

- `input` event
- `.value.length`
- DOM manipulation
- `textContent`
- Conditional statements
- Dynamic CSS updates
- Template literals
